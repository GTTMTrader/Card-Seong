# 카드 리포트 (개인용)

**결제하기 전에** 어떤 카드가 제일 이득인지 계산해주는 웹앱.
단일 HTML 파일이라 빌드 과정 없이 정적 호스팅만 하면 바로 동작함.

## 핵심 기능

1. **결제 전 추천** — 카테고리 + 금액 + 일시불/할부를 넣으면 보유 카드 전부를 계산해서 1위 카드와 예상 혜택액, 2·3위와의 차액까지 보여줌
2. **카드 관리** — 카드 추가/삭제/편집. 연회비, 전월실적, 카테고리별 할인율, 건당 한도, 월 한도를 직접 수정 가능
3. **실적 충족 토글** — 카드사 혜택은 *전월* 실적으로 결정되므로 앱이 자동 판정할 수 없음. 카드 탭에서 카드별로 "실적 충족/미달"을 직접 켜고 끄면 그에 맞춰 계산됨
4. **선택적 기록** — 추천 후 "결제함"을 누르면 저장됨. 월 한도 소진 계산과 다음 달 실적 예측에 사용됨

## 계산에 반영되는 것

- 카테고리별 할인/적립률
- **건당 한도** (예: 미스터라이프는 10%여도 건당 1,000원까지)
- **월 한도** (기록된 혜택 누적분을 차감)
- **금액 구간별 요율** (라스베가스: 10만↑1%, 30만↑1.5%, 50만↑2% / 마카오: 주유·마트 3~10%)
- **정액 캐시백** (토스: 1만원 이상 500원 고정 — 금액이 커도 안 늘어남)
- **할부 시 혜택 제외** 여부

배포된 URL을 Safari로 열기 → 공유 → "홈 화면에 추가" (`icon.png`가 앱 아이콘으로 적용됨)

## 혜택 정보 갱신

카드 혜택은 수시로 바뀌므로 앱 내 **카드 탭 → 카드 선택 → 편집**에서 직접 업데이트하면 됨.
특히 **토스 체크카드는 시즌제 프로모션(현재 시즌6)** 이라 갱신 주기가 짧으니 주기적으로 확인 권장.

## 데이터

모든 데이터는 브라우저 `localStorage`에 저장됨 (서버 전송 없음).
기기 이동/백업은 설정 탭의 Export/Import 사용.
